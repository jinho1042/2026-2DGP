# LEC09 애니메이션 뷰어

`sonic-sprite.png` 스프라이트 시트에서 모든 애니메이션을 자동으로 찾아
순차 재생하는 뷰어입니다. pico2d(Python) 기반입니다.

## 실행 방법

```powershell
# 1) 시트 파싱 (최초 1회 또는 시트를 바꿨을 때)
python sheet_parser.py

# 2) 뷰어 실행
python animation_viewer.py
```

`python sheet_parser.py` 를 실행하면 `sheet_meta.json` 이 생성됩니다.
이미 포함되어 있으므로 뷰어는 바로 실행해도 됩니다.

## 재생 규칙

PRD 요구사항에 따라 다음과 같이 동작합니다.

- 시트의 모든 애니메이션을 순서대로 재생합니다.
- 각 애니메이션은 **5회 반복한 뒤 1회 더** 재생하고 다음으로 넘어갑니다.
- 마지막 애니메이션까지 마치면 처음부터 무한 반복합니다.

## 조작 키

| 키 | 동작 |
|---|---|
| `SPACE` | 재생 / 일시정지 |
| `.` `,` | 한 프레임 앞으로 / 뒤로 |
| `N` | 다음 애니메이션으로 건너뛰기 |
| `R` | 처음부터 다시 |
| `LEFT` / `RIGHT` | 캐릭터 방향 전환 |
| `UP` / `DOWN` | 표시 크기 조절 |
| `[` `]` | 재생 속도 감소 / 증가 |
| `O` | 원본 시트 오버레이 켜기 / 끄기 |
| `0` | 크기 기본값으로 |
| `ESC` | 종료 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `animation_viewer.py` | 뷰어 본체 (재생, 렌더링, 입력 처리) |
| `sheet_parser.py` | 스프라이트 시트 파서 + 메타데이터 생성기 |
| `verify_sheet.py` | 생성된 메타데이터 검증 도구 |
| `sheet_meta.json` | 파싱 결과 (프레임 좌표, 애니메이션 구성) |
| `sonic-sprite.png` | 대상 스프라이트 시트 (399 x 525) |

## 파싱 방법

시트는 균일한 격자가 아니라 자유 배치(free-form) 형태이므로
격자 대신 **알파 채널의 빈틈**을 기준으로 구조를 찾습니다.

1. **PNG 해제** — `sheet_parser.py` 는 외부 라이브러리 없이 PNG 를 직접 읽습니다.
   청크 순회 → `IDAT` zlib 해제 → 스캔라인 필터(None/Sub/Up/Average/Paeth) 역적용.
2. **알파 마스크** — 배경이 완전 투명(alpha 0)이라 알파만으로 그림 여부를 판별합니다.
3. **행 밴드 분리** — 세로로 완전히 비어 있는 행을 경계로 줄 단위를 나눕니다.
4. **연결 요소 분석** — 상하좌우로 이어진 영역을 찾아 프레임 후보를 얻습니다.
5. **노이즈 제거** — 면적이 300픽셀 미만인 조각(잔상, 아티팩트)을 버립니다.
6. **시퀀스 그룹핑** — 줄 안에서 높이가 비슷한 프레임끼리 묶어 하나의 애니메이션으로
   봅니다. 프레임이 3개 미만인 줄은 라벨 텍스트로 판단해 제외합니다.

현재 시트에서 **10개 애니메이션, 총 73프레임**이 추출됩니다.

## 검증

```powershell
python verify_sheet.py
```

다음을 검사합니다.

- 선언된 애니메이션/프레임 개수가 실제 배열 길이와 일치하는지
- 모든 프레임 사각형이 시트 범위 안에 있는지
- 같은 시퀀스의 프레임끼리 겹치지 않는지
- 각 프레임 영역이 실제로 그림으로 채워져 있는지 (채움률 30% 이상)

## 참고

- LEC08 과제의 `animation_viewer.py` 구조를 참고했다.
- 이 pico2d 빌드의 `clip_composite_draw` 는 두 번째 인자로
  '이미지 아랫면으로부터의 거리'(bottom)을 받는다. 메타데이터는 시트 좌표의
  `top` 이므로 `Animation.clip_rect()` 에서 변환한다.
