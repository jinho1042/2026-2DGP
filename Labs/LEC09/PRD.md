# PRD - 애니메이션 뷰어 (Animation Viewer)

## 개요 (Overview)
pico2d를 사용하여 sonic-sprite.png 스프라이트 시트의 모든 애니메이션을 순차 재생/전환하는 애니메이션 뷰어를 구현한다.

## 목표 (Goals)
- Labs/LEC09/ 하위에 애니메이션 뷰어 애플리케이션 구현
- 스프라이트 시트 sonic-sprite.png의 모든 애니메이션 시퀀스를 자동으로 파싱/재생
- 특정 동작(애니메이션)을 처음 5회 반복한 뒤, 1회 더 재생 후 다음 동작으로 전환
- 전체 애니메이션 시퀀스를 모두 재생하면 처음부터 무한 반복
- 화면(창)에 애니메이션이 명확히 보이도록 배치/렌더링
- 최소 20회 이상의 의미 있는 커밋을 남기도록 단계별 구현

## 타겟 스프라이트 시트
- 파일: sonic-sprite.png
- 경로: Labs/LEC09/sonic-sprite.png

## 핵심 요구사항 (Requirements)
1. **전체 시퀀스 순회**: 시트에 포함된 모든 애니메이션을 순서대로 재생한다.
2. **전환 규칙**: 각 애니메이션은 "처음 5회 반복 → 1회 추가 재생(총 6회에 해당하는 패턴 또는 5회 반복 후 다음 전환 전 1회 더) 후 다음 애니메이션으로 전환"한다.
   - PRE-PRD: "각 동작(애니메이션)을 5번 반복 재생하고 1번 더 재생 후 다음 동작으로 간다"
3. **루프**: 모든 애니메이션을 한 바퀴 돌면, 처음 애니메이션부터 다시 무한 반복한다.
4. **가시성**: 창에 애니메이션 프레임이 잘 보이도록 한다.
5. **구현 방식**: 한 번에 모든 코드를 작성하지 말고, 기능별로 구현하며 커밋한다.

## 아키텍처/구현 가이드 (Design Notes)
- pico2d 기반 (python)
- LEC08_Animation의 nimation_viewer.py 패턴을 참고하여 구현
- 애니메이션 정의(프레임 범위/간격 등)는 시트 구조에 맞게 파싱하거나 명시적으로 정의
- 애니메이션 재생 상태(현재 애니메이션 인덱스, 반복 횟수, 프레임 인덱스, 경과 시간 등)를 관리
- 시간 기반 업데이트(tick/frame time)로 자연스러운 재생

## 산출물 (Deliverables)
- Labs/LEC09/ 내 애니메이션 뷰어 실행 파일 (예: nimation_viewer.py 등)
- README/주석 등 필요한 문서(선택) — 과제 취지상 커밋 단위와 동작이 명확해야 함

## 검증 (Acceptance Criteria)
- 프로그램 실행 시, 시트의 모든 애니메이션이 순차적으로 재생된다.
- 각 애니메이션에 대해 5회 반복 후 1회 더 재생 후 다음으로 전환되는지 관찰 가능해야 한다.
- 마지막 애니메이션 후 처음으로 돌아가 무한 반복된다.
- 콘솔/화면 상에 에러 없이 동작한다.
