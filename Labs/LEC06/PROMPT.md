# AI 과제 개발 기록

이 폴더의 `character_draws_ai.py` 는 AI에게 요구사항을 전달해서 만든
완성 코드입니다. `character_draws.py` 는 직접 만든 점진적 개발 과정이고,
두 파일의 결과물(원, 사각형, 삼각형 무한 반복)은 동일합니다.

## 사용한 프롬프트

### 1단계: 요구사항 전달

```
pico2d 를 사용하는 파이썬 실습 과제입니다. character.png 을 불러와서
다음 요구사항을 만족하는 완성 코드를 작성해 주세요.

1. 캐릭터가 원 경로를 한 바퀴 이동한다.
2. 캐릭터가 사각형 경로를 한 바퀴 이동한다.
3. 캐릭터가 삼각형 경로를 한 바퀴 이동한다.
4. 세 운동을 원 -> 사각 -> 삼각 순서로 무한 반복한다.
5. 캔버스 크기는 800x600 이다.
6. 한 프레임 이동 간격은 delay(0.01) 이다.
```

### 2단계: 사각형 경로 명확화

```
사각형은 사각형 모서리에 정확히 닿은 뒤 다음 변으로 이어져야 합니다.
좌표 하한이 MARGIN 이므로 range 의 끝값을 1 씩 늘려 모서리를 빠뜨리지 않게
해 주세요.
```

### 3단계: 삼각형 꼭짓점 지정

```
삼각형 꼭짓점은 A(100, 100), B(700, 100), C(400, 500) 입니다.
두 점을 잇는 선분을 등간격으로 이동하는 공통 함수를 만들고,
꼭짓점 목록을 순회하는 구조로 세 변을 그립니다.
```

### 4단계: 실행 검증

```
최종 코드를 실행했을 때 원 1바퀴, 사각형 1바퀴, 삼각형 1바퀴가
자연스럽게 이어지는지 확인하고, 중복되는 코드는 공통 함수로 합쳐 주세요.
```

## 사용한 pico2d API

- `open_canvas`, `load_image`
- `clear_canvas`, `update_canvas`, `delay`
- `Image.draw(x, y)`

## 개발 순서

| 단계 | 내용 |
| --- | --- |
| 1 | 무한 반복 구조와 운동 함수 뼈대 |
| 2 | 캔버스 준비와 공통 그리기 함수 |
| 3 | 원운동 |
| 4 | 사각 운동 |
| 5 | 삼각 운동 |
