# LEC06 실습 과제 - character_draws.py

## 과제 요구사항

1. 캐릭터가 원 경로를 한 바퀴 이동한다.
2. 캐릭터가 사각형 경로를 한 바퀴 이동한다.
3. 캐릭터가 삼각형 경로를 한 바퀴 이동한다.
4. 위 세 운동을 원 -> 사각 -> 삼각 순서로 무한 반복한다.

## 실행 방법

- 작업 폴더는 `Labs/LEC06` 이다.
- `python character_draws.py` 로 실행한다.
- `character.png` 이 같은 폴더에 있어야 이미지가 나온다.
- 무한 반복이라 종료는 IDE 의 중지 버튼을 사용한다.

## 함수 구성

| 함수 | 역할 |
| --- | --- |
| `draw_character(x, y)` | 지우기 / 그리기 / 화면 갱신 / 대기를 묶은 공통 그리기 함수 |
| `interpolate(x0, y0, x1, y1, t)` | 두 점을 잇는 선분 위의 좌표 계산 |
| `move_circle()` | 원 경로 한 바퀴 이동 |
| `move_top()` `move_right()` `move_bottom()` `move_left()` | 사각형 한 변씩 이동 |
| `move_rectangle()` | 사각형 네 변을 순서대로 연결 |
| `move_segment(x0, y0, x1, y1)` | 두 점 사이를 등간격으로 이동 |
| `move_triangle()` | 삼각형 세 변을 순서대로 연결 |
| `main()` | 세 운동을 무한 반복 |

## 경로 상수

| 상수 | 값 | 의미 |
| --- | --- | --- |
| `FRAME_DELAY` | 0.01 | 한 프레임 대기 시간(초) |
| `CANVAS_W` `CANVAS_H` | 800, 600 | 캔버스 크기 |
| `FULL_TURN` | 360 | 원운동 한 바퀴 각도 범위 |
| `CENTER_X` `CENTER_Y` | 400, 300 | 원운동 중심 |
| `RADIUS` | 200 | 원운동 반지름 |
| `MARGIN` | 50 | 사각형 경로가 화면 가장자리에서 떨어진 거리 |
| `EDGE_STEP` | 5 | 사각형 한 변을 이동하는 간격(px) |
| `TRIANGLE_A` `TRIANGLE_B` `TRIANGLE_C` | (100,100) (700,100) (400,500) | 삼각형 꼭짓점 |
| `TRIANGLE_SEGMENTS` | 40 | 삼각형 한 변을 나누는 구간 수 |

## 개발 순서

1. 전체 반복 구조와 세 운동 함수 뼈대를 먼저 만든다.
2. 삼각형 꼭짓점 상수와 보간 함수를 정의한다.
3. 삼각형 세 변을 한 변씩 나누어 구현하고 실행 확인한다.
4. 원운동 주석을 해제해 세 운동 무한 반복을 완성한다.
5. 화면 출력 코드를 공통 그리기 함수로 통합한다.
6. 캔버스 크기와 경로 값을 상수로 분리한다.
7. 사각형 변 함수 이름을 실제 이동 방향에 맞게 정리한다.
8. `move_triangle` 을 꼭짓점 순회 구조로 리팩터링한다.
9. `main` 진입점을 분리하고 docstring 과 타입 힌트를 추가한다.

## 실행 확인 순서

1. 캐릭터가 화면 중앙에서 출발하는지
2. 원운동이 중심 (400, 300), 반지름 200으로 한 바퀴 도는지
3. 사각형 네 변이 모서리를 정확히 지나는지
4. 삼각형이 마지막 변에서 꼭짓점 `TRIANGLE_A` 로 돌아오는지
5. 원 -> 사각 -> 삼각 순서가 두 번 이상 반복되는지
